# AJ Merlino Portfolio

A reviewable, dependency-free portfolio foundation for design work, music credits, and a personal introduction.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Later deployment

These files are ready for a static Cloudflare Pages project. Connect the eventual GitHub repository, set the production branch, and use the repository root as the build output directory. No build command is needed.
